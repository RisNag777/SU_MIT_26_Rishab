## Organize by class

```
content/
  TEED_5110/
    syllabus/
    readings/
    notes/
    assignments/
  TEED_5111/
    ...
```

Pick a class in the sidebar, then Syllabus / Readings / Notes / Assignments.

## Adding content

Drop files into the matching folder:

- `content/TEED_5110/syllabus/` - course syllabus
- `content/TEED_5110/readings/` - articles and papers (`.md` or `.pdf`)
- `content/TEED_5110/notes/` - your notes (`.md` or `.txt`)
- `content/TEED_5110/assignments/` - prompts and handouts

Refresh the app and the new file appears under that class.

## Listening

Use the **Listen** controls: Play / Pause, -15s / +15s, Speed (0.75x-2x), Stop.
